# EduMatch – Educational Resource Matching Mobile Application

## 📌 Overview
EduMatch is a mobile application designed to help users find and match with suitable educational resources based on their needs and preferences. The system provides a structured platform for discovering learning materials efficiently through a user-friendly interface.

This project was developed as part of a university assignment focusing on mobile application development and backend integration.

---

## ✨ Features
- User authentication (sign up / login) using Firebase Authentication  
- Educational resource matching system based on user preferences  
- Real-time database integration for storing and retrieving data  
- User profile management  
- Clean and responsive mobile UI design  
- Seamless communication between frontend and backend  

---

## 🛠️ Tech Stack
- Frontend: Mobile Application Development (Android / framework used)  
- Backend: Firebase  
- Database: Firebase Realtime Database  
- Authentication: Firebase Authentication
